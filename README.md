# SPK Telkom Regional IV Kalimantan - Sistem Pendukung Keputusan

Sistem Pendukung Keputusan prioritas pelanggan B2B menggunakan metode AHP-SAW.

## Tech Stack
- **Backend**: FastAPI (Python)
- **Data Processing**: Pandas
- **Frontend**: HTML/CSS/JavaScript + Jinja2

## Cara Deploy ke Railway

1. Push folder ini ke GitHub
2. Buat project baru di [Railway](https://railway.app)
3. Connect ke GitHub repository ini
4. Railway akan otomatis detect dan deploy

## Environment
Tidak ada environment variable khusus yang dibutuhkan.
